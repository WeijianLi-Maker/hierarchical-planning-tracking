# Hierarchical Planning and Tracking

This repository contains the implementation and numerical experiments for our work on learning-based certified hierarchical planning and tracking of nonlinear dynamical systems.

## Examples

The repository contains three numerical examples:

- `4dCar/`: 4D car example
- `Bicycle/`: Bicycle model example
- `Quadrotor/`: Quadrotor example

Each folder contains the code and files associated with the corresponding numerical experiment.

## Requirements

The implementation is written in Python. Detailed dependencies and instructions for reproducing the experiments will be provided in each example folder.
